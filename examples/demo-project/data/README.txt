MCODE Demo Project 2.4.1

Import this .mcp file using Minecraft > MCODE (M) > Recursos > Importar proyecto MCODE.

Scripts:
- games/model_spin.mcode: imports models/demo-cube.obj and rotates the mesh.
- games/frame_ring.mcode: draws a local ring using atomic frame updates.

Asset:
- models/demo-cube.obj: a simple static OBJ used to test the model importer.

Use MCODE > Recursos > Ayuda for API documentation. Stop a script with F5 or the Detener button.
